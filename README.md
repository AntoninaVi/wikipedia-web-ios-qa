# Wikipedia Web & iOS QA

QA portfolio project for testing Wikipedia Web and iOS applications.

The project includes test documentation, functional and exploratory testing, 
mobile-specific checks, network scenarios, and bug reports.

## Project Goal

The goal of this project is to practice and demonstrate a structured approach 
to testing a real product on Web and iOS platforms.

Main areas:
- Web testing
- Mobile testing
- Functional testing
- Exploratory testing
- Network testing
- Localization
- Bug reporting
