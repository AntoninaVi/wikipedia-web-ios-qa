# Wikipedia Web Test Cases

## TC-WEB-01 — Search by exact article title

**Precondition:** Wikipedia is open.

**Steps:**
1. Enter a valid article title in the search field.
2. Start the search.
3. Open the matching result.

**Expected result:**
The relevant article opens and its content is displayed correctly.

**Status:** Not Run

---

## TC-WEB-02 — Search for a non-existing article

**Steps:**
1. Enter a query that does not match an existing article.
2. Start the search.

**Expected result:**
The user receives appropriate search results or information that no matching article was found.

**Status:** Not Run

---

## TC-WEB-03 — Change article language

**Precondition:** Open an article available in English and Russian.

**Steps:**
1. Open the language selector.
2. Select another language.

**Expected result:**
The corresponding article in the selected language opens.

**Status:** Not Run
